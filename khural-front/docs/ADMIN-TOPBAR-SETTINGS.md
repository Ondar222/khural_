# Настройки верхней панели админки (`admin-topbar`)

Фронтенд управляет кнопками в верхней панели админ-панели через **уже существующее хранилище настроек** `/api/settings`. Отдельная таблица или миграция бекенду не нужна, если `settings` поддерживает произвольные ключи.

## Используемые эндпоинты

### Чтение

```
GET /api/settings
```

Текущий бэкенд возвращает **массив записей**, а не объект «ключ → значение»:

```json
[
  {
    "id": 12,
    "key": "admin-topbar",
    "value": "{\"showLangToggle\":true,\"langLabelRu\":\"ТЫ\"}"
  }
]
```

Фронтенд находит запись с `key === "admin-topbar"` и берёт её `value`. Дополнительно поддерживаются:

- объект вида `{ "admin-topbar": "..." }` или `{ "admin-topbar": { ... } }`;
- формат `{ key, value }` (например, от `GET /api/settings/admin-topbar`).

Если `value` — JSON-строка, она разбирается; если уже объект, используется как есть.

### Запись

```
PATCH /api/settings
Content-Type: application/json
Authorization: Bearer <token>
```

Тело:

```json
{
  "admin-topbar": "{\"showLangToggle\":true,\"langLabelRu\":\"ТЫ\"}"
}
```

Значение передаётся **строкой JSON** — колонка `settings.value` текстовая, так же сохраняются `site_header`, `site_footer` и другие сложные настройки. Фронтенд при чтении умеет разбирать и объект, но для записи используйте строку.

---

## Формат значения `admin-topbar`

Все поля необязательны: отсутствующие поля получают значения по умолчанию.

| Поле                  | Тип     | По умолчанию               | Назначение                                                                   |
| --------------------- | ------- | -------------------------- | ---------------------------------------------------------------------------- |
| `showLangToggle`      | boolean | `true`                     | Показывать кнопку смены языка                                                |
| `langLabelRu`         | string  | `ТЫ`                       | Надпись на кнопке языка в RU-интерфейсе                                      |
| `langLabelTy`         | string  | `РУ`                       | Надпись на кнопке языка в TY-интерфейсе                                      |
| `showGoToSite`        | boolean | `true`                     | Показывать ссылку на сайт                                                    |
| `siteLabelRu`         | string  | `На сайт`                  | Текст ссылки в RU-интерфейсе                                                 |
| `siteLabelTy`         | string  | `Сайтка`                   | Текст ссылки в TY-интерфейсе                                                 |
| `siteUrl`             | string  | `/`                        | Адрес ссылки. Разрешён относительный путь (`/`, `/news`) или `http(s)://...` |
| `showThemeSwitch`     | boolean | `true`                     | Показывать кнопку смены темы                                                 |
| `themeLabelRu`        | string  | `Смена темы`               | `title`/`aria-label` кнопки темы (RU)                                        |
| `themeLabelTy`        | string  | `Теема солуур`             | `title`/`aria-label` кнопки темы (TY)                                        |
| `showMenuButton`      | boolean | `true`                     | Показывать иконку меню на больших экранах                                    |
| `menuLabelRu`         | string  | `Меню`                     | `aria-label` кнопки меню (RU)                                                |
| `menuLabelTy`         | string  | `Меню`                     | `aria-label` кнопки меню (TY)                                                |
| `showBackToDashboard` | boolean | `true`                     | Показывать кнопку «← Назад в дашборд» (кроме самого `/admin`)                |
| `backLabelRu`         | string  | `Назад в дашборд`          | Текст кнопки возврата (RU)                                                   |
| `backLabelTy`         | string  | `Башкарылга шөлүнге эглип` | Текст кнопки возврата (TY)                                                   |

Полный пример:

```json
{
  "showLangToggle": true,
  "langLabelRu": "ТЫ",
  "langLabelTy": "РУ",
  "showGoToSite": true,
  "siteLabelRu": "На сайт",
  "siteLabelTy": "Сайтка",
  "siteUrl": "/",
  "showThemeSwitch": true,
  "themeLabelRu": "Смена темы",
  "themeLabelTy": "Теема солуур",
  "showMenuButton": true,
  "menuLabelRu": "Меню",
  "menuLabelTy": "Меню",
  "showBackToDashboard": true,
  "backLabelRu": "Назад в дашборд",
  "backLabelTy": "Башкарылга шөлүнге эглип"
}
```

## Правила нормализации на фронтенде

- Булевы значения принимаются как `true/false`, `1/0`, `"1"/"0"`, `"true"/"false"`, `"да"/"нет"`.
- Пустая строка в текстовом поле = значение по умолчанию.
- `siteUrl` без ведущего `/` и без `http(s)://` преобразуется к `/<значение>`.
- Неизвестные поля игнорируются.
- Если настройки недоступны (401/404/ошибка сети), используются значения по умолчанию — админка остаётся работоспособной.

## Поведение на клиенте

- Настройки читаются один раз при первом рендере `AdminShell` и кешируются в модуле.
- После сохранения на странице `/admin/topbar` рассылается событие `khural:admin-topbar-updated`, и верхняя панель обновляется без перезагрузки.
- Если `showMenuButton = false`, кнопка меню всё равно остаётся доступной на экранах ≤ 959 px — иначе сайдбар невозможно открыть.
- Кнопка «Назад в дашборд» не показывается на самом `/admin`.

## Если нужен отдельный эндпоинт

Можно добавить выделенный маршрут, но это **не обязательно**:

```
GET   /api/site/admin-topbar
PATCH /api/site/admin-topbar
```

Тело PATCH — тот же объект, что и в таблице выше (без обёртки в JSON-строку). В этом случае фронтенд нужно перевести с `SettingsApi` на `SiteApi`; текущая реализация использует обычное хранилище `settings`.
